# Machine Learning Coding Project

This repository contains Python labs and homework materials for an applied
machine-learning course. The exercises move from basic regression to
regularized models, classification, and numerical optimization.

## About the PDFs

The PDF in each topic's `Code` or `code` subfolder is a static export of the
associated Python notebook or script, including the code and results displayed
when it was exported. It shows the output of a code run but is not executable.
The homework and problem PDFs in the topic folders are assignment/reference
materials, not outputs generated by the lab code.
